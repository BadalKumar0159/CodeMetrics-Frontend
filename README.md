## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/BadalKumar0159/CodeMetrics-Frontend.git
```

### Install Dependencies

```bash
npm install
```

### Create a `.env` file

```env
VITE_BACKEND_URL=https://codemetrics-backend.onrender.com
```

### Run Development Server

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```
